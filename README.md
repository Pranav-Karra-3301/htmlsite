# htmlsite

A tiny, single-file personal page for Pranav Karra. No framework, no build step, just one hand-written `index.html` with inline CSS and a sprinkle of vanilla JavaScript for the blur-fade-on-scroll effect. It covers the basics: about, publications, experience, projects, and contact.

Deployed as a static page on Vercel (see `vercel.json`).

## Run it locally

Open `index.html` in a browser. That is the whole thing.
